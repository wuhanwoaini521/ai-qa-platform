# Round 18 — Runtime Reliability (multi-instance)

**Status: PASS for multi-process on one host; BLOCKED for multi-host / PostgreSQL.**

## Audit

Claiming was already atomic (`TaskRepository.claim_for_execution` → conditional UPDATE). The failures were all
in *recovery*: four startup routines treated "unfinished" as "abandoned", so a second replica starting up
failed a peer's live task, requirement analysis, exploration run and failure analysis. The write path had no
ownership check, so a zombie process could still overwrite a new owner's terminal state.

## Delivered

- Migration `0020_task_lease`: `lease_owner`, `lease_token`, `lease_expires_at` on `agent_tasks`.
- `claim_for_execution(task_id, owner, lease_seconds)` — takes the task only when it is `PENDING` or
  unfinished *and* unleased/expired; returns the fencing token.
- Heartbeat per running task (`LEASE_SECONDS=90`, `HEARTBEAT_SECONDS=20`) renewing the lease.
- Fencing in `TaskExecutionOrchestrator._finish`: a lost lease records `task.lease_lost` and writes no
  terminal state.
- Graceful stop releases the lease instead of waiting for expiry.
- Staleness windows for the four startup recoveries (`docs/TASK_LEASE.md` §3).

Drill detail (real processes on ports 8030–8033, scratch SQLite copy, real AI provider):

1. instance A becomes ready;
2. the first instance takes a lease when it starts work (token 1, owner = A's runtime id);
3. a peer startup leaves the analysis it is still waiting on running;
4. a peer startup closes an analysis a dead process left behind;
5. a second replica starting up does not block the running task;
6. the task still reaches a terminal state under its own owner (COMPLETED);
7. a restart right after a hard kill leaves an unexpired lease alone (still RUNNING);
8. an expired lease lets a restart recover the orphaned task (BLOCKED).

## Verdicts

- Multi-process consistency (one host, shared SQLite): **PASS**.
- Multi-host / multi-worker (`MULTI_INSTANCE_PASS` in the delivery contract): **BLOCKED** — no PostgreSQL.
- Cancel/retry race across instances: **not fenced** (documented, not fixed).
