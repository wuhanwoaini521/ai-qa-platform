## Real defects found and fixed during acceptance

1. The canvas mode tabs rendered raw i18n keys (`canvasModes.pipeline`) — the tab label map was missing.
2. A duplicate workflow name surfaced the raw `sqlite3.IntegrityError` text — now a `409` with a readable message (`WorkflowNameTaken`).
3. The editor stayed dirty forever after a save, so "publish" could never enable — `sameGraph` compared layout coordinates that the server does not store. Layout is now out of the dirty comparison; auto-layout updates positions directly.
4. A slow initial `load()` could overwrite a definition the user had just created — guarded with a `loadSeq` counter.
