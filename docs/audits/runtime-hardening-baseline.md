## Safety notes

- The existing runtime SQLite database and existing workspace/project/artifact files were not deleted, reset, or inspected for secret contents.
- The API's documented startup migration advanced the existing DB from unversioned schema to Alembic revision `0007`; its row counts were not measured before startup.
- The existing 200 queued jobs were not claimed or executed.
- AI/Jev status probes used configured real services and emitted only allowlisted status fields. No credential value was printed or added to Git.
- `uv sync` failed once on the host's native basedpyright/Node binary dependency; workspace runtime dependencies were then installed with that optional language-server dependency excluded. This exclusion is why the language-server baseline test is unavailable.
