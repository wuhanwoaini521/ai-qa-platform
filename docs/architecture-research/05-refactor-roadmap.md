# 分阶段重构路线（7 个可独立验收的里程碑）

状态：**提案**。未经 Architecture Gate 批准不得开始 M1 之后的任何代码修改。
每个里程碑都必须独立验收、独立回滚；不允许「一次性大重构」。

前置约定：

- 每个里程碑开工前写 1 页设计（问题、范围、前置、验收、回滚）。
- 一个里程碑一个分支/worktree，文件所有权唯一。
- 每个里程碑结束更新 `docs/agent-handoff.md`。
- 任何里程碑都不得引入第二套 Runtime / Agent / Provider，不得改变 Pytest 判定权威。

## M3 — 工具副作用分类与重试策略

| 项 | 内容 |
|---|---|
| 解决的问题 | F5：重试资格由工具名白名单决定，混合只读与生成类工具 |
| 修改范围 | 任务工具注册表（声明 `READ_ONLY` / `IDEMPOTENT_WRITE` / `EFFECTFUL`）；`task_execution_orchestrator.py:374-392` 的重试判定；退避加 jitter |
| 前置依赖 | M2（同一事务与错误处理边界稳定） |
| 预期收益 | 重试行为可解释；新增工具不会默认继承危险重试；借鉴 LangGraph 的错误分类与 jitter |
| 风险与回滚 | 会改变现有重试行为；用配置开关保留旧白名单路径一个版本 |
| 自动化验收 | 每个工具注入「瞬时错误 / 不可重试错误 / 用户取消」三类，断言重试次数、退避区间、终态；Pytest 判定不变 |
| GO 条件 | 全部工具覆盖；无任务成功率下降证据 |
| NO-GO | 若无法为某工具判定副作用类别，保持旧行为并标记 `UNKNOWN`，不得猜测 |

## 明确不在路线内

| 项 | 原因 |
|---|---|
| 统一事件/证据契约层 | 会形成影子真相源；无用户可见故障证据 |
| LangGraph / Browser Use / Skyvern 接入 | 无运行证据；违反单一所有权；Skyvern 有许可证与版本冲突 |
| 跨进程浏览器接管 | 成本高、收益未证明；ROADMAP §2 进行中，不抢跑 |
| 大规模前端重做 | Graphite 方向保持不变；只做只读投影适配 |
| 新消息队列 / 新存储 | 现有 DB 事件游标足够 |

## 每个里程碑的统一验收模板

```text
1. 设计文档：问题 / 范围 / 前置 / 收益 / 回滚
2. 代码：最小改动，复用现有服务与仓储
3. 自动化：定向测试 → 相关集成 → 风险对应回归
4. 双库：SQLite + 隔离 PostgreSQL 16（记录版本与命令）
5. 独立评审：architecture-critic（方案）+ qa-reviewer（证据）
6. 交接：更新 docs/agent-handoff.md
7. 结论：PASS / PARTIAL / FAIL / BLOCKED，附证据
```
